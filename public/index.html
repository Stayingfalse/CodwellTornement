    How the tournament works

    Goal

    Every pair of players teams up against every other player. The tournament ends when that's true for every pair.

    Rounds & matches

    Each round splits the players into groups of four; anyone left over sits out (rotated fairly). Every match runs in its own Discord thread. A match is 6 games — every way the four can pair up, each played twice so both teammates take both roles:

    • Games 1–2 — A & B vs C & D, then roles swapped
    • Games 3–4 — A & C vs B & D, then roles swapped
    • Games 5–6 — A & D vs B & C, then roles swapped

    Games a group already played are skipped, so some matches are shorter. The same four never meet as a group twice. The next round starts when every match in the current one is finished.

    Scoring (per game)

    • Winners: +3 each.
    • Losers: +1 each if they had 3 or fewer cards left, 0 otherwise — or −1 if they hit the assassin.

    Standings show total points, games played and points per game (avg). Sit-outs mean game counts can differ by a few, so compare averages too.

    Logging results

    Post your codenames.game room link in the match thread and results are logged automatically. The buttons in the thread still work if you need them.
